Kattintson egy Q-fejre (vagy Tab + Enter): kiemelődik a hozzá tartozó K/V fej és a ⌊j/G⌋ számítás.

Elméleti, képletből számolt érték (nem mért csúcsmemória): M_KV = 2·L·H_kv·D·B·T·p, 1 GiB = 1 073 741 824 byte. Kezdőállapot: a 3.4.6 labor konfigurációja (L = 32, H_q = 32, D = 128, B = 2, FP16, T = 4096): MHA 4,00 GiB, GQA (H_kv = 8) 1,00 GiB.

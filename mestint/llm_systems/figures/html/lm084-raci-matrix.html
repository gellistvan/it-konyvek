Kattintson egy cellára (vagy Tab + Enter): üres → R → A → C → I → üres. A sor neve melletti „×” gomb törli / visszaállítja a teljes sort (hiányzó hozzárendelés).

    Szabályok (22.4.28): minden feladathoz pontosan egy A és legalább egy R; csak ismert feladat és szerep; R/A/C/I betűk. A validátor a fejezet kódja, kiegészítve a hozzárendelés nélküli feladatok ellenőrzésével. Jelölés: A = sötét kitöltés, vastag keret; R = szürke; C = pontozott; I = üres cella betűvel.

Sematikus, kézzel írt template-ek, nem a tokenizer kimenete; a pontos speciális tokeneket a rögzített tokenizer apply_chat_template
kimenetével kell ellenőrizni (pl. a Qwen2.5 rendszerüzenet nélkül saját alapértelmezett system promptot illeszt be). Tokenszám: durva becslés
(≈ 1 token / 3,5 karakter, speciális tokenenként 1), nem mérés. Szürke keret: speciális token; félkövér: szerepcímke; csíkos háttér: kontextus;
narancs szaggatott keret: a template által áthelyezett vagy a user üzenetbe olvasztott rendszerszöveg.

Számított értékek. Lépésenként n = 1, 3, …, 13; a pontozott sáv a 0 körüli tartomány, ahol |f − Tₙ| < 10⁻⁶ (sin: n = 1-nél |x| < 0,018). Az alsó panel a hibát logaritmikus skálán mutatja; távol a 0-tól rögzített n mellett a hiba nagy (pl. x = 10-nél T₇ messze van sin 10-től). ln(1 + x) sora csak a (−1; 1] intervallumon konvergál (függőleges vonal: x = 1). cos x-nél a páratlan n-hez tartozó Tₙ megegyezik Tₙ₋₁-gyel.

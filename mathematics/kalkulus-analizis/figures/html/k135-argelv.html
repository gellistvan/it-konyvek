p(z) = z⁵ + 3z + 1, gyökök: egy valós ≈ −0,332, négy az 1 < |z| < 2 gyűrűben (tele = a körön belül). A t paraméter 0-tól 2π-ig 60 lépésben fut; a teljes kör után az arg p megváltozása/2π = a körüljárási szám = a belső gyökök száma (r = 1: 1, r = 2: 5). Ha r áthalad egy gyök abszolút értékén, a képgörbe átmegy az origón, és a szám ugrik. A bekapcsolható szaggatott kör a domináns 3z tag képe: r = 1-en |p(z) − 3z| = |z⁵ + 1| ≤ 2 < 3 = |3z|, ezért (Rouché) p-nek is pontosan egy gyöke van a körlapon. Számított adat.

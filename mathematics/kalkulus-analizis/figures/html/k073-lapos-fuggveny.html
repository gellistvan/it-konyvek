P_n a cos x legfeljebb n-edfokú Taylor-polinomja a 0 körül; a Lagrange-becslés |cos x − P_n(x)| ≤ |x|^(n+1)/(n+1)!, mert |cos^(n+1)| ≤ 1. Az f(x) = e^(−1/x²), f(0) = 0 függvény minden deriváltja 0-ban 0, ezért minden Taylor-polinomja azonosan 0, a hiba x ≠ 0-ban f(x) > 0 marad. Számított értékek, nem mérés.

A c pontot (fekete pötty a bal oldali z-síkon) egérrel vagy ujjal is húzhatod.

Számított, modell: w = z + 1/z, a kör középpontja c, sugara R = |1 − c| (átmegy a z = 1 ponton, ennek képe a hátsó él, w = 2). Áramvonalak: ψ = Im[(z − c) + R²/(z − c)] + (Γ/2π)·ln(|z − c|/R), ψ = −1,5 … 1,5, U = 1. Kutta-cirkuláció: Γ = 4πUR·sin β, β = −arg(1 − c); ekkor a hátsó torlópont a hátsó élre kerül. Üres karika: torlópont; + : a ±1 pont. A c a [−0,4; 0] × [−0,3; 0,4] tartományban mozgatható (Re c ≤ 0, hogy a kör a −1 pontot is tartalmazza).

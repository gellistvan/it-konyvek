A cella φ ∈ [30°; 30° + Δφ] szögtartományban, r ∈ [r; r + Δr] sugártartományban fekszik. Pontos terület: ½((r + Δr)² − r²)Δφ = (r + Δr/2)Δr Δφ, tehát a középsugárral számolt közelítés pontos; az r belső sugárral számolt r Δr Δφ relatív hibája −Δr/(2r + Δr), ami Δr → 0 esetén 0-hoz tart. Számított geometria.

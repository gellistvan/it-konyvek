f(x, y) = x²y/(x⁴ + y²), f(0, 0) := 0. A szintvonalak az y = kx² parabolák (k/(1 + k²) = c), a c = 0 szint a két tengely; az árnyalás f előjelét és nagyságát mutatja. Minden y = mx egyenes mentén mx/(x² + m²) → 0, az y = cx² parabola mentén f ≡ c/(1 + c²), c = 1-nél 1/2: a kétváltozós határérték nem létezik. Számított, nem mérés.

Számított értékek, nem mérés. A = [a1 a2 a3], a1 = (1, 0, 0), a2 = (0, 1, 0), a3 = (1, 1, ε) (a fejezet A_kozeli mátrixa), b = (1, 1, δ). Pontos megoldás: x3 = δ/ε, x1 = x2 = 1 − δ/ε; det = ε, relD = ε/√(2+ε²), cond ≈ 3/ε (a szinguláris értékekből, JS-ben Jacobi-módszerrel). A Cramer-hányadosok a fejezet cramer3 függvényének átiratai (3×3-as determinánsok). A „könyv két esete” gomb a 10.4.9 kódkimenetét adja: δ = 0 → x = (1; 1; 0), δ = 10⁻⁸ → x = (0; 0; 1), a reziduum mindkettőnél 0.

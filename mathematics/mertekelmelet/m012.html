4.5 Komplex számok és a komplex exponenciális

4.5.1 Motiváció: miért van szükség komplex számokra a Fourier-analízishez?

A Fourier-sorok és a Fourier-transzformáció nyelve elválaszthatatlan a komplex számoktól. A valós sin\sin és cos\cos függvények helyett sokkal tömörebb egyetlen függvénnyel dolgozni: az eixe^{ix} komplex exponenciálissal. Ha például egy rezgést szeretnénk leírni, a cos⁡(ωt)\cos(\omega t) és sin⁡(ωt)\sin(\omega t) pár helyett az eiωte^{i \omega t} egyetlen függvény hordozza ugyanazt az információt, ráadásul a szorzási és deriválási szabályai rendkívül egyszerűek. Ez az alfejezet felépíti azt a minimális komplex szám- és integrálfogalmat, amelyre a későbbi Fourier-elmélet épül.

4.5.2 Szemléletes kép: a komplex sík és az egységkör

A komplex számokat a sík pontjaiként képzeljük: a vízszintes tengely a valós, a függőleges a képzetes rész. Az eixe^{ix} értékek az origó körüli egységkörön helyezkednek el, mert abszolút értékük mindig 11. Az alábbi pontok az eikπ/4e^{i k \pi/4} értékek k=0,1,…,7k = 0, 1, \dots, 7 esetén:

A nyolc pont egy szabályos nyolcszöget rajzol ki, és jól mutatja, hogy a komplex exponenciális a szög növelésével körbejár az egységkörön. A 45∘=π/445^\circ = \pi/4 lépésekben felvett pontok koordinátái cos⁡(kπ/4)\cos(k\pi/4) és sin⁡(kπ/4)\sin(k\pi/4), tehát a két valós függvény együtt jelenik meg a komplex szám két komponenseként.

4.5.3 Komplex számok: definíció és alapműveletek

Definíció. Komplex számnak (complex number) nevezzük a z=a+biz = a + bi alakú kifejezéseket, ahol a,b∈ℝa, b \in \mathbb{R}, és ii az imaginárius egység, amelyre i2=−1i^2 = -1. Az aa szám a zz valós része (real part), a bb a képzetes része (imaginary part); jelölésük Re⁡z=a\operatorname{Re} z = a és Im⁡z=b\operatorname{Im} z = b. A komplex számok halmaza ℂ\mathbb{C}.

Két komplex számot komponensenként adunk össze, a szorzatot pedig a szokásos algebrai szabályokkal számoljuk ki, felhasználva, hogy i2=−1i^2 = -1: ha z=a+biz = a + bi és w=c+diw = c + di, akkor z+w=(a+c)+(b+d)i,zw=(ac−bd)+(ad+bc)i. z + w = (a + c) + (b + d)i, \qquad z\,w = (ac - bd) + (ad + bc)i. Például (1+2i)+(3−i)=4+i, (1 + 2i) + (3 - i) = 4 + i, és (1+2i)(3−i)=3−i+6i−2i2=3+5i+2=5+5i. (1 + 2i)(3 - i) = 3 - i + 6i - 2i^2 = 3 + 5i + 2 = 5 + 5i.

Definíció. A z=a+biz = a + bi komplex szám konjugáltja (conjugate) z¯=a−bi. \overline{z} = a - bi. A zz abszolút értéke vagy modulusa (absolute value, modulus) |z|=a2+b2. |z| = \sqrt{a^2 + b^2}.

A konjugálás és az abszolút érték alapvető tulajdonságai:

  • zz¯=|z|2z\,\overline{z} = |z|^2,
  • z+w¯=z¯+w¯\overline{z + w} = \overline{z} + \overline{w} és zw¯=z¯w¯\overline{z\,w} = \overline{z}\,\overline{w},
  • |zw|=|z||w||z\,w| = |z|\,|w|.

Az első azonosság bizonyítása egyetlen sor: ha z=a+biz = a + bi, akkor zz¯=(a+bi)(a−bi)=a2−(bi)2=a2+b2=|z|2. z\,\overline{z} = (a + bi)(a - bi) = a^2 - (bi)^2 = a^2 + b^2 = |z|^2.

Ellenpélda. Az abszolút érték négyzetét nem szabad összetéveszteni a komplex szám négyzetével. Például z=iz = i esetén |i|2=1,i2=−1. |i|^2 = 1, \qquad i^2 = -1. Ez az egyik leggyakoribb hiba a komplex számokkal való számolásban.

Megjegyzés. A komplex számokon nem létezik a valós rendezést kiterjesztő rendezett teststruktúra, azaz olyan rendezés, amely kompatibilis az összeadással (ha z<wz < w, akkor z+u<w+uz + u < w + u minden uu-ra) és a pozitív elemmel való szorzással (ha z<wz < w és u>0u > 0, akkor zu<wuzu < wu), és amely a valós számokon a szokásos rendezést adja. Valóban, egy ilyen rendezésben minden négyzet nemnegatív, és 1=12>01 = 1^2 > 0. Mivel i2=−1i^2 = -1, a −1-1 is nemnegatív volna, azaz −1≥0-1 \ge 0 és 1>01 > 0 egyszerre teljesülne, ami lehetetlen. Ezért komplex számoknál a rendezés helyett az abszolút értékkel mérünk.

4.5.4 A komplex exponenciális és az Euler-formula

Definíció. Minden valós xx számra legyen eix=cos⁡x+isin⁡x. e^{ix} = \cos x + i \sin x. Ezt hívjuk Euler-formulának (Euler’s formula). Általánosabban, ha z=a+biz = a + bi komplex szám, akkor a komplex exponenciálist (complex exponential) így értelmezzük: ez=ea(cos⁡b+isin⁡b), e^{z} = e^{a}(\cos b + i \sin b), ahol eae^{a} a szokásos valós exponenciális függvény.

Az Euler-formula nem „varázslat”: a cos⁡x+isin⁡x\cos x + i \sin x függvény deriváltja éppen önmagának ii-szerese. Valóban, ha f(x)=cos⁡x+isin⁡xf(x) = \cos x + i \sin x, akkor f′(x)=−sin⁡x+icos⁡x=i(cos⁡x+isin⁡x)=if(x), f'(x) = -\sin x + i \cos x = i(\cos x + i \sin x) = i f(x), és f(0)=1f(0) = 1. Ugyanezeket a tulajdonságokat várjuk el egy eixe^{ix} jelölésű függvénytől is: f′(x)=ieixf'(x) = i e^{ix} és f(0)=1f(0) = 1. Ezért természetes a fenti definíció.

Tétel. Minden x,y∈ℝx, y \in \mathbb{R} esetén

  1. |eix|=1|e^{ix}| = 1,
  2. ei(x+y)=eixeiye^{i(x+y)} = e^{ix}\,e^{iy},
  3. e−ix=eix¯e^{-ix} = \overline{e^{ix}},
  4. ddxeiax=iaeiax\frac{d}{dx} e^{i a x} = i a\, e^{i a x} minden valós aa konstansra.

Bizonyítás.

  1. Az abszolút érték definíciója szerint |eix|2=cos⁡2x+sin⁡2x=1, |e^{ix}|^2 = \cos^2 x + \sin^2 x = 1, tehát |eix|=1|e^{ix}| = 1.

  2. A trigonometrikus addíciós képletekből: ei(x+y)=cos⁡(x+y)+isin⁡(x+y)=(cos⁡xcos⁡y−sin⁡xsin⁡y)+i(sin⁡xcos⁡y+cos⁡xsin⁡y). e^{i(x+y)} = \cos(x+y) + i \sin(x+y) = (\cos x \cos y - \sin x \sin y) + i(\sin x \cos y + \cos x \sin y). Ugyanakkor eixeiy=(cos⁡x+isin⁡x)(cos⁡y+isin⁡y)=cos⁡xcos⁡y−sin⁡xsin⁡y+i(sin⁡xcos⁡y+cos⁡xsin⁡y). e^{ix}\,e^{iy} = (\cos x + i \sin x)(\cos y + i \sin y) = \cos x \cos y - \sin x \sin y + i(\sin x \cos y + \cos x \sin y). A két kifejezés valós és képzetes része egyenlő, így egyenlők.

  3. Mivel cos\cos páros, sin\sin pedig páratlan: e−ix=cos⁡(−x)+isin⁡(−x)=cos⁡x−isin⁡x=cos⁡x+isin⁡x¯. e^{-ix} = \cos(-x) + i \sin(-x) = \cos x - i \sin x = \overline{\cos x + i \sin x}.

  4. A definícióból komponensenként deriválva: ddxeiax=ddx(cos⁡(ax)+isin⁡(ax))=−asin⁡(ax)+iacos⁡(ax)=ia(cos⁡(ax)+isin⁡(ax)). \frac{d}{dx} e^{i a x} = \frac{d}{dx}\big(\cos(a x) + i \sin(a x)\big) = -a \sin(a x) + i a \cos(a x) = i a\big(\cos(a x) + i \sin(a x)\big). ∎

Példa. A z=1+iz = 1 + i szám exponenciális alakja. Először |z|=12+12=2|z| = \sqrt{1^2 + 1^2} = \sqrt{2}. A szög π/4\pi/4, mert cos⁡(π/4)=sin⁡(π/4)=1/2\cos(\pi/4) = \sin(\pi/4) = 1/\sqrt{2}. Így 1+i=2eiπ/4. 1 + i = \sqrt{2}\, e^{i \pi/4}. Ha ezt négyzetre emeljük, a |zw|=|z||w||z\,w| = |z|\,|w| szabály és a kitevő-azonosság alapján (1+i)2=(2)2ei2π/4=2eiπ/2=2i, (1 + i)^2 = (\sqrt{2})^2\, e^{i 2 \pi/4} = 2 e^{i \pi/2} = 2i, ami megegyezik a közvetlen algebrai számolással.

Megjegyzés. A z=reiθz = r e^{i \theta} alakot exponenciális alaknak nevezzük. Ha z≠0z \neq 0, akkor r=|z|>0r = |z| > 0, és a θ\theta szög csak modulo 2π2\pi egyértelmű, mert eiθe^{i\theta} 2π2\pi szerint periodikus. A z=0z = 0 esetben r=0r = 0, és a θ\theta tetszőleges, hiszen a 0=0⋅eiθ0 = 0\cdot e^{i\theta} előállításban a szög nem hordoz információt. A komplex számok szorzása ebben az alakban geometriailag nagyon szemléletes: ha w=seiφ≠0w = s e^{i\varphi} \neq 0, akkor a z=reiθz = r e^{i\theta} számmal vett szorzat zw=rsei(θ+φ), z\,w = rs\, e^{i(\theta + \varphi)}, azaz a ww-vel való szorzás ss-szeresére skáláz és φ\varphi szöggel forgat. A nullával való szorzás ezzel szemben minden pontot a 00-ba visz, tehát nem forgatás és nem is skálázás a szó szokásos értelmében.

4.5.5 Komplex értékű függvények integrálja

A Fourier-elméletben gyakran kell integrálnunk einxe^{i n x} típusú függvényeket. Ehhez elég a valós és a képzetes részt külön-külön integrálni.

Definíció. Legyen f:[a,b]→ℂf: [a, b] \to \mathbb{C} olyan függvény, amelynek valós és képzetes része is Riemann-integrálható. Ekkor az ff integrálját így értelmezzük: ∫abf(x)dx=∫abRe⁡f(x)dx+i∫abIm⁡f(x)dx. \int_a^b f(x)\,dx \;=\; \int_a^b \operatorname{Re} f(x)\,dx \;+\; i \int_a^b \operatorname{Im} f(x)\,dx.

Ebből azonnal következik, hogy az integrálás lineáris: ha c1,c2c_1, c_2 komplex konstansok, akkor ∫ab(c1f(x)+c2g(x))dx=c1∫abf(x)dx+c2∫abg(x)dx. \int_a^b \big(c_1 f(x) + c_2 g(x)\big)\,dx = c_1 \int_a^b f(x)\,dx + c_2 \int_a^b g(x)\,dx. A Newton–Leibniz-formula is érvényben marad: ha FF olyan komplex értékű függvény, amelynek valós és képzetes része primitív függvénye a megfelelő részeknek, akkor ∫abf(x)dx=F(b)−F(a). \int_a^b f(x)\,dx = F(b) - F(a).

Továbbvitt eredmény. Ez a komponensenkénti integrálfogalom terjeszthető ki később a Lebesgue-integrál komplex értékű függvényekre is; ezt használjuk az Integrálható függvények: L¹ és a komplex értékű eset alfejezetben.

4.5.6 Az ortogonalitási integrál levezetése

A Fourier-sorok elméletében alapvető szerepet játszik a következő integrál.

Tétel. Minden n∈ℤn \in \mathbb{Z} egész számra ∫02πeinxdx=2π𝟏{0}(n), \int_0^{2\pi} e^{i n x}\,dx \;=\; 2\pi\,\mathbf{1}_{\{0\}}(n), ahol 𝟏{0}(n)\mathbf{1}_{\{0\}}(n) az az indikátorfüggvény, amely 11-et ad, ha n=0n = 0, és 00-t különben.

Bizonyítási terv. Két esetet különböztetünk meg. Ha n=0n = 0, az integrandus az azonosan 11 függvény, így az integrál triviálisan 2π2\pi. Ha n≠0n \neq 0, megkeressük az integrandus primitív függvényét, és alkalmazzuk a Newton–Leibniz-szabályt.

Bizonyítás.

  • Ha n=0n = 0, akkor ei0x=e0=1e^{i 0 x} = e^0 = 1, tehát ∫02π1dx=2π. \int_0^{2\pi} 1\,dx = 2\pi.

  • Legyen most n≠0n \neq 0. A deriválási szabály szerint a 1ineinx\frac{1}{i n} e^{i n x} függvény deriváltja ddx(1ineinx)=1in⋅ineinx=einx. \frac{d}{dx}\left(\frac{1}{i n} e^{i n x}\right) = \frac{1}{i n} \cdot i n\, e^{i n x} = e^{i n x}. Ezért ∫02πeinxdx=1ineinx|02π=1in(ei2πn−e0). \int_0^{2\pi} e^{i n x}\,dx = \frac{1}{i n} e^{i n x}\Big|_{0}^{2\pi} = \frac{1}{i n}\big(e^{i 2\pi n} - e^{0}\big). Mivel nn egész, az addíciós képletből ei2πn=cos⁡(2πn)+isin⁡(2πn)=1+i⋅0=1. e^{i 2\pi n} = \cos(2\pi n) + i \sin(2\pi n) = 1 + i \cdot 0 = 1. Így a különbség 1−1=01 - 1 = 0, tehát az integrál értéke 00. ∎

Továbbvitt eredmény. Ez az eredmény az ortogonalitás magja. A tételből n,m∈ℤn, m \in \mathbb{Z}-re azonnal adódik, hogy ∫02πeinxeimx¯dx=∫02πei(n−m)xdx=2π𝟏{0}(n−m), \int_0^{2\pi} e^{i n x}\,\overline{e^{i m x}}\,dx = \int_0^{2\pi} e^{i(n-m)x}\,dx = 2\pi\,\mathbf{1}_{\{0\}}(n-m), azaz n=mn = m esetén az integrál értéke 2π2\pi, n≠mn \neq m esetén pedig 00. Ezt használjuk a Trigonometrikus rendszer és Fourier-együtthatók alfejezetben. Ott a periódus [0,1)[0,1), ezért az x=2πtx = 2\pi t helyettesítéssel áttérünk a t∈[0,1)t \in [0,1) változóra: ∫01e2πinte2πimt¯dt=12π∫02πei(n−m)xdx=𝟏{0}(n−m). \int_0^1 e^{2\pi i n t}\,\overline{e^{2\pi i m t}}\,dt = \frac{1}{2\pi}\int_0^{2\pi} e^{i(n-m)x}\,dx = \mathbf{1}_{\{0\}}(n-m). A két normalizálás tehát csak egy 2π2\pi tényezőben tér el: a [0,2π][0,2\pi] intervallumon az ortogonalitási integrál értéke 2π2\pi, a [0,1)[0,1) perióduson 11. A |eix|=1|e^{i x}| = 1 azonosságot pedig alapvetően használjuk a Fourier-transzformáció definíciója L¹-en alfejezetben, ahol a transzformált korlátosságát éppen ez adja.

4.5.7 Python-illusztráció: komplex számok és a numerikus integrál

A következő kód a NumPy segítségével ellenőrzi az Euler-formulát és az ortogonalitási integrált numerikusan. A Python a képzetes egységet 1j-vel jelöli, a kimenetben j szerepel. Ez a kód numerikus szemléltetés, nem bizonyítás: a diszkretizáció és a lebegőpontos ábrázolás kerekítési hibát okoz.

import numpy as np

# Euler-formula ellenőrzése x = pi/4 esetén
x = np.pi / 4
z = np.exp(1j * x)
print(f"e^(i pi/4) = {z:.4f}")
print(f"cos(pi/4) + i sin(pi/4) = {np.cos(x) + 1j*np.sin(x):.4f}")
print(f"|e^(i x)| = {np.abs(z):.6f}")

# Az ortogonalitási integrál numerikus közelítése n = 3 esetén
n = 3
t = np.linspace(0, 2*np.pi, 10000)
integral_approx = np.trapezoid(np.exp(1j*n*t), t)
print(f"n = {n}: |integral| ~ {abs(integral_approx):.4f}")

# Ugyanez geometriai összegként: k = 0, ..., 9998, r = exp(2 pi i * 3 / 9999)
N = 9999
r = np.exp(2j*np.pi*n/N)          # r != 1, de r**N = 1
geom = np.sum(r**np.arange(N))
print(f"geometriai osszeg: |S| ~ {abs(geom):.4f}")

4.5.8 Tipikus hibák és félreértések

  1. Az abszolút érték négyzetének és a komplex négyzetnek az összekeverése. Ahogy fentebb láttuk, |i|2=1|i|^2 = 1, de i2=−1i^2 = -1. Általában |z|2=zz¯|z|^2 = z\,\overline{z}, és ez csak valós zz-re egyenlő z2z^2-tel.

  2. Az Euler-formula kitevőjének hibás kezelése. Az ei(x+y)=eixeiye^{i(x+y)} = e^{ix}\,e^{iy} azonosság igaz, de ebből nem következik, hogy eix=eiye^{ix} = e^{iy}-ból x=yx = y volna: az eixe^{ix} függvény 2π2\pi szerint periodikus, ezért a helyes következtetés x−y∈2πℤx - y \in 2\pi\mathbb{Z}. Például ei2πn=1=ei⋅0e^{i 2\pi n} = 1 = e^{i\cdot 0} minden egész nn-re, jóllehet 2πn≠02\pi n \neq 0, ha n≠0n \neq 0. A valós exe^x függvény ezzel szemben injektív: ott ex=eye^x = e^y-ból x=yx = y következik.

  3. Komplex integrál számításakor a valós és képzetes rész különválasztásának elhagyása. A komplex integrált nem szabad valós integrálként kezelni, és az integrandus kitevőjét sem szabad megváltoztatni: ∫einxdx\int e^{i n x}\,dx-et nem enx/ne^{n x}/n-ként kell írni (ez a kitevő hibája). A helyes primitív függvény n≠0n \neq 0 esetén 1ineinx=−ineinx\frac{1}{i n} e^{i n x} = -\frac{i}{n} e^{i n x}, amelynek deriváltja 1in⋅ineinx=einx\frac{1}{i n}\cdot i n\, e^{i n x} = e^{i n x}; n=0n = 0 esetén pedig az integrandus azonosan 11, így a primitív függvény xx. Mindkét eset a komplex Newton–Leibniz-szabályból adódik, amelyet komponensenként, a valós és képzetes rész külön integrálásával definiáltunk.

4.5.10 Megoldások

4.5.10.1 (a)

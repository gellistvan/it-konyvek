(x₀ a felső sávra kattintva is áthelyezhető)

fₙ = 1_[j/2ᵏ, (j+1)/2ᵏ], n = 2ᵏ + j, 0 ≤ j < 2ᵏ. Minden k-szinten valamelyik sáv tartalmazza x₀-t, ezért fₙ(x₀) végtelen sokszor 1 és végtelen sokszor 0, miközben ‖fₙ‖₁ = 2⁻ᵏ → 0. Az f₂ᵏ = 1_[0, 2⁻ᵏ] részsorozat minden x₀ > 0 pontban 0-hoz tart. Számított értékek a definícióból, nem mérés.

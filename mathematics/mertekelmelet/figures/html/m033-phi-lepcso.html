φₙ = min(n, 2⁻ⁿ⌊2ⁿf⌋); a bizonyítás 3. lépésének az aktuális x-hez tartozó esete kiemelve:

1. eset: f(x) ≥ n + 1 ⇒ φₙ(x) = n < n + 1 = φₙ₊₁(x)
2. eset: n ≤ f(x) < n + 1 ⇒ φₙ(x) = n ≤ φₙ₊₁(x), mert k ≥ n·2ⁿ⁺¹
3. eset: f(x) < n ⇒ kₙ₊₁ ≥ 2kₙ, ezért φₙ₊₁(x) = kₙ₊₁/2ⁿ⁺¹ ≥ kₙ/2ⁿ = φₙ(x)

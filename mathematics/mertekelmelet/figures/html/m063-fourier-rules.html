g(x) = e^{2πibx} f(s(x − a)), f = 1_[0,1]; a szabálytáblázatból ĝ(ξ) = e^{−2πia(ξ−b)} (1/|s|) f̂((ξ − b)/s), f̂(ξ) = e^{−πiξ} sin(πξ)/(πξ). Az eltolás csak a fázist változtatja, a moduláció b-vel eltolja a spektrumot, az s-szeres összenyomás s-szer szélesebbé és 1/|s|-szer alacsonyabbá teszi; s < 0 tükröz (s = −1: f̂(−ξ)). Az s = 0 értéket a program ±0,05-re cseréli. Számított értékek a zárt képletekből.

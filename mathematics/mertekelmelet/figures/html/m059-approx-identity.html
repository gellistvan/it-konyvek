Dobozmagnál (f*φ_ε)(x) = max(0, min(ε, x+1) − max(−ε, x−1))/(2ε), az L¹-hiba 0 < ε ≤ 2 esetén pontosan ε; Gauss-magnál (f*φ_ε)(x) = ½[erf(√π(x+1)/ε) − erf(√π(x−1)/ε)], az L¹-hibát a program numerikusan integrálja. A ±1 pontban dobozmagnál (f*φ_ε)(±1) = 1/2 (ε ≤ 2), Gauss-magnál ½·erf(2√π/ε) → 1/2, miközben f(±1) = 1: a szakadási pontban nincs pontonkénti konvergencia f-hez. Számított értékek a zárt képletből, nem mérés.

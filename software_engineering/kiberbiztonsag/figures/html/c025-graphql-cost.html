Költségszabály a fejezetből: skalár 1, objektum 1 + gyermek, lista 1 + gyermek · szorzó, alias = külön mezőpéldány. Alapbeállítás: szorzó 10, küszöb 1000, mélységi korlát 7, 300 alias → 2222 / 111 / 600. A szorzót a kikényszerített oldalméretből kell venni (lapozás nélkül a WideQuery költsége korlátlan).

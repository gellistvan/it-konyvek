Kattints egy kártyára (vagy Tab + Enter): megmutatja, melyik feltétel teljesül.

A detect.py szabálya: baseline = a request kisbetűsítve tartalmazza a „union select” szöveget; tuned = ezen felül a „--” is szerepel. A címkét (label) a detektáló nem látja. Kártya: A = attack (vastag keret), B = benign; ✓ = a szabály riaszt, ✗ = nem. Jelölés: TP tömör, FP ferde vonalkázás, FN pontozás, TN üres.

Technika: 




Sematikus modell (nem mérés): szaggatott = DMA, folytonos = CPU-másolás, pontozott = csak hivatkozás. read+write: 2 DMA + 2 CPU-másolás, 2 syscall; sendfile: 2 DMA + 1 CPU-másolás (SG-NIC-kel 0), 1 syscall; splice: 2 DMA + 0 CPU, 2 syscall; MSG_ZEROCOPY: 1 DMA a rögzített felhasználói lapokról, értesítés az errqueue-n (loopbacken a kernel mégis másol: COPIED).

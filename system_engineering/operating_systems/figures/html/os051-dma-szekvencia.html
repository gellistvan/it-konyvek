Sematikus: QEMU edu, koherens puffer, egy olvasó; az időtengely nem arányos. A regiszterértékek a QEMU edu specifikációja szerint (T-O6-014): DMA kész = 0x100, ack = 0x64, EDU-puffer = 0x40000, iránybit 0x02 (1 = EDU → RAM). A 11. lépés a második átvitel (3–10. lépés fordított iránnyal) összevonva. Tömör nyíl = MMIO írás/hívás, szaggatott = DMA, cikcakk = IRQ, pontozott = visszatérés.

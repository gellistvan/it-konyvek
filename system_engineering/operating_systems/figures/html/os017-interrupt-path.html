Sematikus (nem kernelfutás). x86: a fejezet x86-32 irq_entry/irq_dispatch/tick_handler példája, IRQ 0 → vektor 32. AArch64: GICv3, EL1 fizikai timer PPI 14 = INTID 30. EOI nélkül az INTID active marad, nem jön új megszakítás; TVAL újraprogramozása nélkül a szintvezérelt timer azonnal újra jelez (T-O2-072).

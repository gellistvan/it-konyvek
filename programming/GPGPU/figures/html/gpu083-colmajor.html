Kattints A egy cellájára (vagy használd a Tab + Enter billentyűt): kiemelődik a memóriacím és a képlet. Column-major: cím = i + j·lda (lda ≥ 2 = sorok száma, a többlet pöttyözött padding); row-major: cím = i·3 + j. Az alsó sor a felcserélt cublasSgemm-hívás (n = 2, m = 2, k = 3, d_B, 2, d_A, 3, d_C, 2) eredménye: row-major C. 0-alapú index, float, alpha = 1, beta = 0.

13.3 labor: a program kimenetéből (átlagos idő, ms)
A bájt- és FLOP-szám a labor kódjából: SAXPY 12N B, 2N FLOP; Horner 8N B, 6N FLOP; FMA-lánc 8N B, (8·256 + 3)N FLOP. Mért GFLOPS = FLOP / idő; a pont az ugyanilyen alakú, üres jelölő.

Roofline: P_max(I) = min(P_peak, I·B_peak), I_ridge = P_peak/B_peak. Modellből számolt felső korlát, nem mérés; a teli jelölő a várt (modell)pont, az üres a beírt mért érték. Példaadatok: RTX 3080 29,77 TFLOPS FP32, 760 GB/s; FP64-tető az FP32 1/64-e.

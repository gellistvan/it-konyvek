Elméleti modell a labor képleteivel, nem mérés: H2D = 2·N·4 B / BPCIe, D2H = N·4 B / BPCIe, egy kernel = 3·N·4 B / (0,56·BGPU) (a 0,56 hatásfok a fejezet 0,015 ms-os becslését adja vissza A100-on), CPU = k·3·N·4 B / BCPU. A „k művelet” azt modellezi, hogy az adat egyszer megy fel és le, közben k kernel fut a GPU-n (a CPU ugyanennyi menetet végez). A kernelindítás (0,005–0,02 ms) nincs benne; PCIe elméleti értékkel, a valós transzfer lassabb. Kerekítés nélkül a kezdőállapot 0,408 ms (a fejezet kerekített összege 0,26 + 0,015 + 0,13 = 0,405 ms).

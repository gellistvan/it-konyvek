A store buffer az x86-TSO modell szemléltetése; a C++ modell a z = 0-t architektúrától függetlenül megengedi acq/rel mellett. Az utasítások: g++ 15.2 -O2, x86-64 (seq_cst store: xchgb; release store: movb; load: movzbl). A lépésgombok csak a modellben megengedett lépéseket kínálják; a szkript az összes elérhető állapotot felsorolta: seq_cst mellett egyetlen sorrend sem ad z = 0-t.

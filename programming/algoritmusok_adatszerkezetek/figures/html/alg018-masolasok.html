A fejezet Append-je: bővítés, ha size = capacity; a régi size elem másolódik. Szorzó: kezdőkapacitás 1, új kapacitás max(capacity + 1, ⌊α·capacity⌋); konstans: kezdőkapacitás c, új kapacitás capacity + c. Egységköltség = egy elem másolása, a beírás nélkül. Elméleti számlálás, nem mérés. Kezdőállapot: α = 2, c = 10, n = 100 (127 és 450 másolás, mint a könyv ábráján).

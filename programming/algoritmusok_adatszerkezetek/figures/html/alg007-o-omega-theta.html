Folytonos vastag = T(n), szaggatott = c₂·f(n), pontozott = c₁·f(n); ★ = egész n ≥ n₀, ahol a megfelelő egyenlőtlenség sérül. Az IGAZ/HAMIS ellenőrzés az n₀ ≤ n ≤ 2000 egészeken fut (véges ablak, nem bizonyítás). A görbék csak szemléltetésként folytonosak. Kezdőállapot: a 3.2.4 példája, c₁ = 3, c₂ = 12, n₀ = 1.

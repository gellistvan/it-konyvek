A pontok egérrel/ujjal húzhatók (0,5-ös rácsra). A számítás egy beágyazott, determinisztikus SMO (lineáris kernel); hard margó = C = 10 000. SV = a margón vagy azon belül fekvő pont (y·(w·x + b) ≤ 1,001), duális súlya lehet 0 is (a könyv példájában a (5, 4)). Nem szeparálható adatnál a hard margó nem létezik: válasszon soft margót.

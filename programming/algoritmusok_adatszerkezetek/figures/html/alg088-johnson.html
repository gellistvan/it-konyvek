ŵ(u, v) = w(u, v) + h(u) − h(v). Minden h mellett, amelyre minden ŵ ≥ 0 (érvényes potenciál), a Dijkstra helyes, és d(u, v) = d̂(u, v) − h(u) + h(v); a Bellman–Ford adta h = δ(s, ·) mindig ilyen.
